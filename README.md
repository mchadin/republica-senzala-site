# República Senzala

Site para República Senzala, Ouro Preto - MG.

O projeto reúne a história da república, informações sobre a estrutura da casa, moradores, ex-alunos, confraternizações e um acervo histórico de fotos.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- Bootstrap 5.3.3
- Bootstrap Icons
- Google Fonts
